## What it is
**Description:** Turn a tally into symbols one key's worth at a time, give the pictograph a title and a key, stand it up the page, and read a column by its symbols and the key.
**Why:** Draw a pictograph from a tally chart, one symbol for each key's worth, give it a title and a key, stand it up the page, and read a column by its symbols and the key.
**Look:** A tally chart at the left, an empty pictograph at the right with a title strip and a key box, a tray of plain picture symbols, and a side ruler.
**Context:** Grade 4. An adult sees a chart being drawn. What is actually being learnt is that a pictograph is drawn one symbol for each key's worth, that it needs a title and a key to be read at all, and that a column standing up the page is read exactly as a row is. The chapter's one pictograph drawn up the page numbers its side from nought to ten under the heading number of children, but each face stands for two children, so the numbers count faces. This tool reads every column by its symbols and the key, and its side ruler numbers only in the data's own units. The exercise's symbol is printed as a copyright sign, and the tool offers plain pictures only.
**For the child:** Set the key first. Stamp one symbol for each key's worth. Give the pictograph a title and a key. Stand it up the page. Count the symbols in a column. Then use the key.
**Teaching notes:** Tally the class's favourite fruits before the tool is opened, and build the pictograph up the wall with one sticky note for every two children. Ask how many children one column shows, and why the number of notes is not the answer on its own. The chapter's one pictograph drawn up the page numbers its side from nought to ten in ones under the heading number of children, but each face stands for two children, so the numbers count faces, and the tiger's column reaches eight where sixteen children chose it. Read every column by counting its symbols and using the key. If the class numbers a side, number it in the data's own units, two, four, six, or leave it unnumbered. The exercise's symbol is printed as a copyright sign; draw a plain picture instead, a small face or a television. The same exercise calls its categories a programme, a channel and kinds of show; call them kinds of television show. Every count in that exercise is even and its key is two, so no half symbol is needed there.

## Phases (what each mount shows and does; the words are in tool.tsx)

### 1 · From a tally to symbols
**Screen:** a tally chart at the left, an empty pictograph row at the right, and the key dial set
**Does:** stamps symbols into the row, each taking one key's worth of marks from the tally, until the tally row is used up
**Win:** the last marks fade from the tally as the last symbol lands, and the row's count matches
**Feels:** each stamp takes its handful of marks from the tally, and the row is done when the tally is
**Goal:** one symbol is drawn for each key's worth, so the count shared into the key gives the number of symbols
**Observe:** Each stamp faded two marks from the tally, and the row was finished when the tally row was used up.
**Wrong (each is a traceback on the working area):**
- tries to stamp one face for each child, fourteen faces for fourteen children. → each stamp fades two marks from the tally, and after seven stamps the tally row is used up. The eighth stamp does not land, and the row stands at seven faces. Lifting a face gives its two marks back to the tally.
- stamps one face for each bundle of five in the tally, two faces for fourteen. → the first stamp fades two marks out of the first bundle, not the whole bundle, and the bundle is seen split. The row goes on to seven faces as the tally fades two marks at a time.
- wants the favourite row's pictures drawn bigger or further apart, so it reaches past a row with more symbols. → every stamp lands the same picture at the same size, at the next place along from the row's left edge. A symbol dragged further along slides back, and the row stands at its true length, shorter than the row with more symbols.
**Misconception to break:** Drawing one face for each child, 14 faces, as though each face stood for one child.

### 2 · A title and a key
**Screen:** a finished set of rows with the title strip and the key box still outlined blanks
**Does:** writes a title that says what the data is about and fills the key box
**Win:** the title and the key fill in, and every row's number appears at its end
**Feels:** the chart can be read only once it says what it counts and what each picture is worth
**Goal:** every pictograph needs a title that says what the data is about and a key that says what one symbol stands for
**Observe:** The pictograph would not show as finished until its title and its key were both filled.
**Wrong (each is a traceback on the working area):**
- leaves the key off because the pictures are easy to count, so a reader takes each picture as one flower. → the pictograph will not show as finished, and the key box stays an outlined blank. Each row's tag stays empty, and the running count shows symbols only. The child's rows stay as drawn.
- writes a title that names the chart but not the data, such as My Pictograph. → the title strip keeps the child's words. A question card beside it asks what was counted, and the strip is offered back with the child's words still in it.
- writes the key as one flower for five, without saying five of what. → the key box keeps the number, and its unit stays an outlined blank. Each row's tag writes its number with the same blank after it.
**Misconception to break:** Leaving the key off because the pictures are easy to count, so a reader takes each picture as one flower.

### 3 · A pictograph that stands up
**Screen:** the finished pictograph across the page with the turn control waiting
**Does:** stands it up the page, then reads one column by counting its symbols and using the key
**Win:** the rows swing up into columns, every symbol keeps its place, and the column's number matches its row's
**Feels:** the rows swing up, every symbol keeps its place, and a column is read just as its row was
**Goal:** a pictograph drawn up the page is read the same way, by counting symbols and using the key
**Observe:** The rows swung up into columns, and every column's number matched its row's.
**Wrong (each is a traceback on the working area):**
- counts the column's symbols and gives six as the children who come by bicycle, forgetting the key once it stands up. → the column's symbols light from the bottom one at a time into the running count, six. The key's three is taken under each, and eighteen lands above the column. The child's six stays in the slot.
- on a pictograph drawn by hand, hangs each column's symbols from the top, so a short column starts high and looks tall. → the child's drawing stays on its card beside the board. The turned pictograph stacks every column from the bottom line, so a short column is short at the foot, and the columns' numbers are the same as before.
**Misconception to break:** Treating the column as a new kind of chart and reading how high it reaches, instead of counting its symbols and using the key.

### 4 · Numbers beside a column
**Screen:** one column of faces with the key above it, a question card describing a side numbered one per face, and the side ruler blank
**Does:** counts the faces, uses the key, and numbers the side ruler in children as each face is tapped
**Win:** the side ruler reads in children up to the top face, and the answer matches the column
**Feels:** the numbers climb up the side by the key's worth, and the top one is the column's number
**Goal:** a column's data is its symbols times the key, whatever numbers stand beside it
**Observe:** The side ruler wrote two, four, six up the column, and its top number matched the column's number.
**Wrong (each is a traceback on the working area):**
- reads seven off the numbered side as the children, when those numbers count faces. → the side ruler is laid blank beside the column. As each face is tapped from the bottom it writes two, four, six in amber, and it reaches fourteen at the top face. The child's seven stays beside the old side's seven.
- numbers the side of their own upward pictograph one per face, under the heading number of children. → the side ruler is laid beside the child's side and numbers itself in children as each face is tapped, two, four, six, up to the key times the faces. The child's numbers stand beside it, and the heading is set against both.
**Misconception to break:** Reading 7 off the numbered side as the number of children, when those numbers count faces.

## Delight
The first phase, when the last symbol of a row lands and its tally row is used up. The faded marks drift across the stage and settle inside the symbols, a key's worth in each whole symbol and half that in a half. Every symbol is seen holding its own marks. A tap on any symbol afterwards makes its marks glow inside it for a moment. It runs as often as a finger likes, nothing is marked either way, and the voice says nothing at all while it happens.

**General miss line:** Lift the last symbol off, and watch how many marks it gives back.

## Answer key
A pictograph is drawn by choosing a symbol and a key, then drawing one symbol for each key's worth in every row: the count shared into the key's worth gives the number of symbols, and a half symbol stands for half a key's worth left over. Every pictograph needs a title, which says what the data is about, and a key, which says what one symbol stands for. A pictograph can run across the page or up it, and a column is read exactly as a row is, by counting its symbols and using the key. Numbers written beside a column count whatever they were written for; when they count symbols, the column's data is still its symbols times the key.

## Student controls
- **Symbol tray**: holds plain picture symbols: faces, cups, trees, kites and buses
- **Key dial**: sets what one symbol stands for before any symbol is stamped
- **Stamp**: puts one symbol in a row and takes one key's worth from its tally
- **Half stamp**: offered only when exactly half a key's worth is left in a tally row
- **Title strip**: an outlined blank the pictograph cannot be finished without
- **Key box**: an outlined blank for the key, also needed to finish
- **Turn**: stands the pictograph up the page, rows becoming columns from the bottom
- **Side ruler**: numbers a column's side in the data's own units as each symbol is tapped
