## What it is
**Description:** Set a key, write a word in code with it, and decode a message by undoing the key.
**Why:** Set a key, write a word in code with it, and read a code back by undoing the key, then find out why the key is needed at all.
**Look:** Two rings of letters one inside the other, a number band that clips round them, and a message strip along the foot of the stage.
**Context:** Grade 4. An adult sees a puzzle. What is actually being learnt is that a code is one pattern applied to every letter, that the key is the rule, and that decoding is the same rule run backwards. The page's summary box says that to decode a secret code we must know the key, and the locked mode makes that true in the child's hands rather than on the page: without the key, several readings stand on the strip at once and nothing chooses between them.
**For the child:** Turn the inner ring to set the key. Tap each letter of your word. Read its partner into the strip. To decode, turn the ring back the same way. Without the key, try one key at a time.
**Teaching notes:** Make the paper code wheel from the activity before the tool is opened: two circles with the alphabet round each edge, pinned at the centre. Turning the inner circle settles the one thing a written table cannot, that the letter after Z is A, because on a circle there is no end to fall off. The page shows three kinds of key: each letter as its place in the alphabet, with a note that the numbers can run the other way; each letter moved one place on; and a note swapping the first letter with the last. The printed exercise then uses a key that moves each letter two places on, so decoding it means going two places back. Use other words and other keys in class, so the printed messages are still worth decoding when the class reaches them. The page calls the numbers of a code digits, when most of them have two digits; call them numbers. Its summary box prints the sentence about the key with no spaces between the words. Write it on the board with the spaces put back and read it aloud: to decode a secret code, we must know the key. Then let the locked mode prove it.

## Phases (what each mount shows and does; the words are in tool.tsx)

### 1 · A key says what each letter stands for
**Screen:** the outer ring with the number band clipped round it and an empty message strip
**Does:** taps each letter of a word and reads its number off the band into the strip
**Win:** the numbers drop into the strip, one under each letter
**Feels:** every letter has one partner under the key, and the same letter always gets the same one
**Goal:** a key says what every letter stands for, such as A as one up to Z as twenty-six
**Observe:** Every letter had one number under the key, and the same letter always had the same number.
**Wrong (each is a traceback on the working area):**
- counts the alphabet from zero, so every number comes out one too small and KITE is written ten, eight, nineteen, four. → the band counts from A again, lighting each letter as it is counted and writing one under A. The child's numbers stay in the strip, and the band's numbers are written above them, each one bigger. Nothing is cleared.
- reads the numbers off the band as if it ran from A as one, when it has been flipped to run from A as twenty-six. → the small arrow on the band lights, with A's own number written beside it. The child's line stays in the strip, and the flipped band's number for each letter is carried down beside it, so S, U and N read eight, six and thirteen.
**Misconception to break:** Counting the alphabet from 0 instead of 1, so every number comes out one too small.

### 2 · Moving each letter along
**Screen:** both rings, the inner ring turned a few places on, and a word waiting
**Does:** carries each letter of the word to its partner on the inner ring
**Win:** the coded word fills the strip, and a letter near the end is carried round to the start
**Feels:** every letter moves the same number of places, and the ring carries Z on round to A
**Goal:** a key can move every letter the same number of places on, and Z comes round to A
**Observe:** A letter carried on past Z came round to A without anything special happening.
**Wrong (each is a traceback on the working area):**
- stops at Z because nothing comes after it, and leaves that letter out of the code. → the carry line from Z runs on round the ring one place at a time, past the tick where Z meets A, lighting A, then B, then C. Each landing is numbered as it lights. The child's code keeps its empty box, and the ring's landing is written beside it.
- counts the letter it starts on as the first place, so three places on from O lands on Q instead of R. → the carry runs one place at a time from O, and the first number is written on P, the first landing. O itself is left unnumbered. The child's Q stays in the strip, and the count stops on R with three written over it.
**Misconception to break:** Stopping at Z because nothing comes after it, and leaving the letter out.

### 3 · Decoding means undoing the key
**Screen:** a coded message in the strip with its key written beside it
**Does:** turns the inner ring back by the key and reads each letter's partner
**Win:** the message reads out in plain letters, and a letter that passed A comes round from Z
**Feels:** the key moved each letter on, so undoing it moves each one back just as far
**Goal:** decoding moves each letter back as far as the key moved it on
**Observe:** Coding the decoded word again gave back the code, letter for letter.
**Wrong (each is a traceback on the working area):**
- moves each letter three places on again instead of back, reading F D N H as I G Q K. → the child's reading is coded again through the key and set under the message. It comes out L J T N, further from the code rather than back to it. Undo then turns the wheel back three places and carries each code letter home. Both readings stay in the strip.
- going back past A, stops at A, so D F P never becomes a word. → the carry line runs back from D one place at a time, past the tick where A meets Z, lighting C, B, A, Z and then Y. Each landing is numbered as it lights. The child's box keeps what was written, and the ring's landing is written beside it.
**Misconception to break:** Moving the letters three more places on, which hides the word further instead of finding it.

### 4 · Without the key the code stays locked
**Screen:** a coded message with its key hidden and the trial rows empty
**Does:** tries one key after another, writes each reading out, and says what would settle it
**Win:** several readings stand in the trial rows, and the right one lights only when the key is shown
**Feels:** several readings stand side by side, and nothing on the strip says which one the sender meant
**Goal:** without the key the same code can be read in more than one way
**Observe:** Two keys read the same message two ways, and nothing on the strip chose between them.
**Wrong (each is a traceback on the working area):**
- reads the code with A as one, finds a word, and takes it as certain. → the trial rows keep the child's reading and add the others, each written out in full with its key at the left of its row. Four, fifteen, seven reads D O G in one row and W L T in the next. No row is marked, and the key tag stays closed until the key is shown.
- tries only the key with A as one, and gives up when it does not make a word. → the locked mode sets out the other keys the chapter uses, the flipped band, a key that moves letters along, and the swap. It writes a trial row for each in turn. The child's single row stays at the top.
**Misconception to break:** Taking the first reading that makes a word as certain, when another key could hide another word.

## Delight
The third phase, once the message reads out in plain letters. The plain word lifts off the strip and rides forward round the wheel through the key, letter by letter, and each letter lands exactly on the code box it came from. The two lines of the strip then stand one above the other, joined letter to letter by short vermilion ticks. It runs as often as a finger likes, nothing is marked, and the voice says nothing while it happens.

**General miss line:** Carry the letter again, one place at a time, and count as you go.

## Answer key
A key says what each letter stands for. With A as one, each letter stands for its place in the alphabet, up to Z as twenty-six, and the numbers can run the other way, with A as twenty-six and Z as one. A key can move every letter the same number of places on; the alphabet goes round like a circle, so moving on past Z carries on round from A. Another key swaps the first letter with the last, the second with the second last, and so on. To decode, undo the key: move each letter back by as many places as the key moved it on, going round from Z when you pass A, or read each number back to its letter. Without the key a code cannot be read for certain, because the same letters or numbers stand for different things under different keys.

## Student controls
- **Outer ring**: holds the alphabet from A to Z round a circle
- **Inner ring**: turns to set how many places on the key moves each letter
- **Number band**: gives each letter its place, one to twenty-six, or the other way round
- **Swap key**: pairs the first letter with the last, the second with the second last, and so on
- **Message strip**: takes a word a letter at a time and shows it in code
- **Undo**: runs the wheel backwards by the key to decode
- **Locked mode**: hides the key so that keys can be tried one at a time
- **Trial rows**: write each trial reading out in full under the last

## Textbook (this topic)
**Pages:** 114, 115
**Key terms:** secret code, key, decode
A secret code is made with a key that says what each letter stands for, and it is read by undoing the key. A key says what each letter stands for, a number or another letter. To decode, undo the key, moving each letter back as far as the key moved it on. Without the key, the same code can be read in more than one way. Four, because D is the fourth letter. A key tells you what every letter stands for. Anyone holding the key can write the code or read it. DBU. C moves to D, A to B and T to U. Nothing comes after Z, so Z goes round to A. H I. To decode, move each letter back by as many places as the key moved it on. Going back past A carries on round from Z. No. With A as one it spells CAB, but another key gives other letters. That is why a secret code keeps its secret.
